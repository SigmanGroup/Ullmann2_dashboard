## Dashboard for Predicting Effective Substrate Combinations for Cu-catalyzed Ullmann Coupling with N1, N2-diarylbenzene-1,2-diamine Ligands
The dashboard can be accessed at https://sigmangroup.github.io/Ullmann2_dashboard/. All static GitHub Pages dashboard was generated from the amine library, aryl-bromide library, and all other necessary files that are provided in the manuscript, and at https://github.com/SigmanGroup/Ullmann_v2

### What does the dashboard do?

The dashboard allows users to evaluate new amine and aryl bromide combinations within the chemical space explored in this study. Users can:

- Input the SMILES of an amine and an aryl bromide.
- Identify exact matches for the input substrates within the corresponding virtual descriptor libraries.
- Identify the most structurally similar library compound using Tanimoto similarity when an exact match is unavailable.
- Visualize the input and matched substrate structures along with their match information and similarity scores.
- Locate the substrate combination on the two-descriptor reactivity threshold plot.
- Project the substrate combination into the PCA-derived chemical space using the fitted scaling and PCA transformations.
